# What IX-AGI must demonstrate to establish genuinely more general intelligence

This document is a benchmark *contract*, not a claim of achieved benchmarks.

1. Encounter unseen task families without task-specific algorithm selection.
2. Acquire new transition dynamics and independently derive successful plans.
3. Invent new reusable representations, not only recombine fixed predicates.
4. Identify errors attributable to its own inference strategy and revise that strategy.
5. Transfer learning across multiple distinct sensory/action representations without human label correspondence.
6. Retain prior competence under nonstationary adaptation; measure forgetting.
7. Use previous experience to improve learning rate on unseen task families.
8. Diagnose and recover from a temporarily failed/lesioned callosal connection.
9. Demonstrate improvements over **both actual donors** and a compute/capacity-matched centralized design.
10. Confirm reproducible real-environment outcomes, not only symbolic host adapters.
11. Never bypass the Ada execution gate; verify appropriate SPARK obligations separately.

The first build targets a narrow but real capability in which the right hemisphere
represents external-object effects that BlackFox's own command-local induction
explicitly rejects. This addresses only a small part of item 2. Items 1, 3–10
are not met by the present runtime and must not be advertised as achieved.
